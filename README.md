# سیستم ثبت موبایل GitHub
1. `setup.html` را باز کن و رمز اصلی را انتخاب کن.
2. فایل `data.enc` را دانلود و در همین repository آپلود کن.
3. `index.html` را با GitHub Pages منتشر کن.
4. در صفحه، Owner و Repository را وارد کن.
5. برای ذخیره تغییرات، یک GitHub token با دسترسی `Contents: write` لازم است.
6. همان رمز اصلی را در هر گوشی وارد کن.
**مهم:** repository عمومی است؛ `data.enc` قابل دانلود است ولی متن اطلاعات داخل آن رمزنگاری شده است. رمز را در کد یا GitHub قرار نده.
